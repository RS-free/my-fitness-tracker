# Мій фітнес-щоденник

Простий щоденник тренувань, що працює прямо в браузері, без сервера.

## Можливості

- вибір програми тренування на день;
- облік випитої води (ціль — 12 склянок, 3 літри);
- відмітки прийому вітамінів і добавок;
- нотатки про харчування та самопочуття;
- контрольні зважування з прогресом і відстанню до цілі;
- історія збережених днів.

Дані зберігаються автоматично в `localStorage` браузера, тож вони є лише на тому пристрої й у тому браузері, де ти їх вводив.

## Як запустити

Відкрий файл `index.html` у браузері.
